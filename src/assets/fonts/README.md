# lichess-chess.woff2

The move list's figurines (♔♕♖♗♘): lichess's `lichess-chess` face — Noto Sans with figurines by
the pgn4web authors — cut down to those five glyphs and remapped from the piece letters lichess
draws them at onto the figurine codepoints. The cut is chessdocs' `scripts/fonts/chess.ts`; the
source is [`public/font/lichess-chess.sfd`](https://github.com/lichess-org/lila/blob/master/public/font/lichess-chess.sfd)
in lila.

Licensed GPLv2 or later, like the face it is cut from — unlike the rest of this repo, which is MIT.
